## System Requirements

### OS Requirements

DiffGSP is implemented in Python and can run on both Windows and Linux. The package has been tested on the following systems:

- Linux (recommended): CentOS 7.9.2009, Ubuntu 18.04, Ubuntu 20.04
- Windows: Windows 10

### Python Dependencies

DiffGSP requires Python >= 3.9. The package has been tested with Python 3.9.0.

The following package versions have been tested:
